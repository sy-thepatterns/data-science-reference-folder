# Reinforcement Learning

## Definition

Reinforcement learning studies agents that choose actions, observe consequences, and learn policies intended to maximize long-run reward.

## Notation

| Symbol | Meaning |
|---|---|
| $\mathcal{S}$ | State space. |
| $\mathcal{A}$ | Action space. |
| $s_t,a_t,r_t$ | State, action, and reward at time $t$. |
| $P(s^{\prime}\mid s,a)$ | Transition distribution. |
| $R$ | Reward function or reward distribution. |
| $\pi(a\mid s)$ | Policy: distribution over actions in a state. |
| $\gamma$ | Discount factor between zero and one. |
| $G_t$ | Discounted return from time $t$. |
| $J(\pi)$ | Expected performance of policy $\pi$. |
| $Q^\pi(s,a)$ | Expected return after action $a$ in state $s$ and then following $\pi$. |

## Intuition

A supervised learner is shown the correct answer. A reinforcement-learning agent is only told how good the consequences were, sometimes much later. It must discover which actions caused those consequences while balancing safe known actions against informative experiments.

## Learning Signal

Rewards and state transitions produced by interaction or logged behaviour. Correct action labels are generally unavailable.

## Main Settings

| Setting | Description |
|---|---|
| Model-free | Learn values or policies without explicitly learning transition dynamics. |
| Model-based | Learn or use a model to plan future actions. |
| On-policy | Learn about the same policy that generates experience. |
| Off-policy | Learn about one policy from data generated by another. |
| Offline | Learn only from a fixed logged dataset, without new exploration. |

## Formal Setup

A Markov decision process is $(\mathcal{S},\mathcal{A},P,R,\gamma)$. The discounted return is

$$
G_t
=
\sum_{k=0}^{\infty}\gamma^k r_{t+k}
$$

and a policy aims to maximize

$$
J(\pi)=\mathbb{E}_{\pi}[G_0]
$$

Value-based, policy-gradient, actor–critic, and planning algorithms are different ways to estimate or optimize this objective.

## Typical Objectives and Strategies

- Expected discounted or average return.
- Risk-sensitive or constrained return for safety-critical systems.
- Sample-efficient exploration.
- Robust performance under model error and environmental change.
- Offline policy improvement subject to support constraints.

## Data Structure and Splitting

The split must follow the unit expected to generalize: examples, people, entities, time periods, environments, or tasks. Preprocessing and model selection must use training data only. Any feedback-dependent collection process must be reproduced inside each training run rather than performed once using the full dataset.

## Evaluation

- Report return distributions and uncertainty across many independent seeds.
- Compare against scripted, random, behavioural, and strong non-learning baselines.
- Measure sample efficiency, compute, safety violations, and worst-case performance—not only final mean reward.
- For offline evaluation, report importance-weighting or model-based assumptions and effective sample size.
- Separate training environments from unseen layouts, dynamics, initial states, and disturbances.
- Test reward robustness and inspect behaviour for specification gaming.

## Strengths

### Long-term statistical objective

The return $G_t=\sum_{k\ge0}\gamma^k r_{t+k}$ makes delayed consequences part of the estimand. Supervised one-step prediction cannot by itself represent how an action changes future states and therefore future rewards.

### Bellman decomposition

The Bellman relation expresses a long-horizon value recursively:

$$
Q^\pi(s,a)
=
\mathbb{E}[r+\gamma Q^\pi(S',A')\mid s,a]
$$

This converts a potentially infinite return into repeated conditional-expectation estimation and enables temporal-difference learning.

### Exploration as information collection

The value of an action includes both immediate reward and information that improves future decisions. Bandit confidence bounds make this explicit by adding an uncertainty bonus that shrinks roughly as an action’s sample count grows.

### Policy optimization

Policy-gradient methods estimate $\nabla J(\theta)$ directly, allowing optimization of stochastic decisions rather than only fitting a predictive surrogate. Baselines can reduce gradient variance without changing its expectation.

### Model-based sample reuse

A learned transition model can generate many planning rollouts from limited real experience. When model bias is controlled, this lowers environmental sample cost by exchanging it for estimation and computation.

### Risk and constraint extensions

The objective can include expected cost, tail risk, or constraints rather than only mean return. This supports decision criteria closer to safety requirements, although estimating rare risk remains difficult.

## Limitations and Failure Modes

### Return variance grows with horizon

A Monte Carlo return sums many random rewards. With weak dependence, variance accumulates across terms; large $\gamma$ preserves distant rewards but increases effective horizon and estimation variance. Bootstrapping reduces variance while introducing approximation bias.

### Sample complexity

State–action coverage grows rapidly with dimensionality. In tabular settings, estimation error depends on visits to each relevant $(s,a)$ pair; with function approximation, guarantees require stronger smoothness, realizability, or concentrability assumptions.

### Off-policy importance-weight variance

Correcting from behavior policy $\mu$ to target policy $\pi$ uses products of ratios $\prod_t\pi(a_t\mid s_t)/\mu(a_t\mid s_t)$. These products can have enormous or infinite variance when policies differ, making offline evaluation statistically unstable.

### Reward is a noisy proxy

Optimization is consistent for the specified reward, not for the designer’s unstated goal. Even a precisely estimated high-return policy can exploit omitted costs or measurement loopholes.

### Confounding in logged data

Offline trajectories often omit variables that influenced historical actions and outcomes. Sequential ignorability and support assumptions are needed for causal policy evaluation; predictive fit to logged rewards is insufficient.

### Distribution shift under policy improvement

A new policy visits states poorly represented under the behavior policy. Value-error bounds can scale with a concentrability coefficient measuring this mismatch, which may be extremely large.

### Instability from the deadly triad

Function approximation, bootstrapping, and off-policy updates can produce divergent value estimates. Each is statistically useful, but their combination can break contraction or independent-sampling arguments.

### High-variance empirical evaluation

Environment randomness, initialization, exploration, and optimization create large seed variance. Reporting only the best seed is a selection-biased estimate of expected performance.

### Partial observability

If the recorded state is not Markov, $P(s_{t+1}\mid s_t,a_t)$ omits relevant history. Value estimates then average across hidden situations requiring different actions.
