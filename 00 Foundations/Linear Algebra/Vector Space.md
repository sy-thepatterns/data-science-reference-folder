# Vector Space

## Definition

A vector space over a field $$\mathbb{F}$$ is a set $$V$$ with vector addition and scalar multiplication satisfying the vector-space axioms.

## Relevance to Machine Learning

Feature vectors, parameter vectors, gradients, and many learned representations are elements of finite-dimensional vector spaces such as:

$$
\mathbb{R}^{p}
$$
